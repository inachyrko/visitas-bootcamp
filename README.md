*Un KPI (Key Performance Indicator, o indicador clave de rendimiento) es una medida cuantificable que evalúa el progreso o el éxito de una empresa, proyecto, equipo o proceso frente a un objetivo específico.*

# Visitas y conversiones · Bootcamp Data Analyst

-*Conceptos basicos:*
## Definición de KPI de conversion : es un número que te dice si algo va bien o mal respecto a un objetivo. El KPI de conversión, o tasa de conversión, mide qué porcentaje de las personas que ven algo acaban haciendo la acción que tú quieres.

Proyecto de prácticas de **Git y GitHub**. Los datos son **100 % sintéticos**.

## Pregunta de negocio

¿Qué proporción de visitas termina en inscripción?

- **Grano del dato:** una fila por visita.
- **Numerador:** visitas que se convierten (`conversion = 1`).
- **Denominador:** todas las visitas observadas.
- **Indicador inicial:** tasa de conversión (3 de 8 = 37,5 %).

## Ejecutar

Desde esta carpeta, abre la terminal y ejecuta:

```bash
python analisis.py
```

No se requieren paquetes externos. El código utiliza la librería estándar de Python.

## Archivo de trabajo

- `analisis.py`: lee el CSV y calcula visitas, conversiones y tasa.
- `datos/visitas.csv`: registros **ficticios** de ejemplo.
- `.gitignore`: evita incluir ficheros locales/sensibles por accidente.
